# Delivery OTP Shortcut (iPhone)

`Delivery OTP (unsigned).shortcut` is the whole filter in one Shortcut, so you don't build anything by hand.
It reads an SMS (or a WhatsApp message you share), and only if it is clearly a delivery OTP it sends
**company, item, order tail and code** to your Pi. The message text never leaves the phone.
The Pi checks those four fields again.

Generated by `python3 -m otp_relay.shortcut.build_shortcut` from `rules.json`, so the Shortcut and the Pi use the
same word lists. Rebuild and re-sign it after changing `rules.json`.

**Not tested on a real iPhone yet.** It was built to Apple's file format from memory and checked by tests for its
logic and structure, not by importing it. If the import or a step fails, send the exact message you see.

## 1. Sign it (needs a Mac, once)

iOS only installs signed Shortcuts. On a Mac running macOS 12 or later:

```
shortcuts sign --mode anyone --input "Delivery OTP (unsigned).shortcut" --output "Delivery OTP.shortcut"
```

## 2. Install on the iPhone

AirDrop (or iCloud Drive) the signed file to the iPhone and open it. Shortcuts asks two questions:

1. **Address of your Pi:** `http://<Pi Tailscale IP>:8765/ingest`
2. **OTP_RELAY_TOKEN:** the secret you set on the Pi (16+ characters).

Tap **Add Shortcut**. (If the iPhone refuses with "untrusted shortcut", the file isn't signed.)

## 3. Run it on every SMS

Shortcuts > **Automation** > **+** > **Message**:
- **Message Contains:** `OTP`  (leave Sender empty)
- **Run Immediately**, turn **Notify When Run** off.
- Action: **Run Shortcut** > choose **Delivery OTP**. Tap its input and choose **Shortcut Input** (the message).

## 4. WhatsApp OTPs

The same Shortcut shows in the Share Sheet. Long-press the WhatsApp message > **Share** > **Delivery OTP**.
WhatsApp messages can't start an automation, so this is one tap per OTP.

## 5. Test

Share this text to the Shortcut (Notes app > select the text > Share > Delivery OTP):

> Amazon: your order of Philips trimmer, order 408-1234567-7654321 is out for delivery. Share OTP 5927 with the delivery agent.

Ask the Pi (`/query`) or the voice hub for the Amazon OTP: it should say "Amazon: Philips trimmer (order …4321)". Then share a fake bank message,
"HDFC Bank: OTP 123456 for transaction of Rs 500". Nothing should be sent.
